# Interior walls and grass investigation — 1 October 2026

Closed exterior room loops already compute true face intersections and store mitred footprints. Open interior partitions did not receive that pass: the wall tool created an extended rectangular box. Consequently a partition could extend into a receiving wall, and ordinary edge rendering outlined buried caps and crossing edges. The 90° selection also preceded later face/midpoint/inference snaps, allowing those refinements to release its selected axis.

The renderer now derives open interior mitres and near-face abutments from neighbouring walls at the same floor level. Stored wall dimensions/IDs and existing exterior mitres remain editable; hosted openings continue through the normal wall geometry pipeline. Edge segments split at neighbouring wall boundaries and buried pieces are omitted. They look continuous while remaining separate selectable walls; this is not a destructive CSG merge. Very shallow/parallel corners retain their existing fallback. Junction resolution is memoized by wall geometry, so furnishing changes do not rebuild partition geometry or lose current wall materials.

Interior starts can snap to real footprint corners, including mitred room elbows. The click path preserves the previewed corner. Later endpoint refinements preserve the selected locked axis, and Shift/the lock-off setting still allows free angles. Room eligibility now uses actual slab/room polygons and elevations: an L-house's exterior notch is not accepted merely because it lies inside the walls' overall bounding box.

Grass exclusion had a padded polygon AABB but an unpadded final polygon test. The final test now includes edge clearance, and slab transforms match Three rotations/quaternions. Architectural slab polygons are authored in local XY and rotated onto the ground; legacy unrotated XZ slab data remains supported. This prevents roots at slab boundaries and allows a small clearance for blade bending/mask interpolation.

Verification: 54 focused wall, opening, room-assembly and grass tests; TypeScript; production bundling; browser preview with an actual terrain/grass field, polygon slab and T/open-corner partitions. Tests cover mixed wall thickness, arbitrary shared rotation, storey separation, retained door holes, buried-edge splitting, axis preservation, mitred-corner snapping and concave L-floor eligibility. The user's exact saved model was not available; arbitrary custom/tilted/scaled walls and genuine mobile GPU performance remain outside this verification.
