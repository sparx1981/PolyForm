# Split-rail fence generator (vendored)

Unmodified copy of the geometry modules from
[maxliebscher/SplitRailFenceThreejs](https://github.com/maxliebscher/SplitRailFenceThreejs)
at commit `0fd666125d0df3cda9d12a32f2c0e942031ca032`, MIT licensed (see `LICENSE`).

PolyForm calls it only through `../fenceBuild.ts`. The standalone editor, worker and camera
tour modules were not copied. Update by copying the same files from a newer upstream commit.
